    From form to function

    1. Choose the documented Source plan and identify its principal spaces.
    2. Switch to Invented PCB; inspect the modern V1 → SW1 → R1 → D1 → GND path, including the return trace.
    3. Open SW1. Current drops to zero. Close it and change voltage or resistance; observe Ohm's law.
    4. Export a vector concept or machine-readable illustrative netlist. Use KiCad for actual footprints, copper clearances, DRC/ERC, and production outputs.
    5. Compare two layouts: does changing the shape change the electrical result? No. Topology and component values determine this model's result.

    Inspired by a student project in MIT's Fab Academy that translated the Medinet Habu floor plan into a battery-powered PCB. That project is a modern design, not ancient electrical evidence. Read the build notes.
